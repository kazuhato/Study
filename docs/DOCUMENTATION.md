# Документация проекта StudyNotesExporter

## 1. Назначение плагина
**StudyNotesExporter** — плагин для **IntelliJ IDEA**, предназначенный для сохранения выделенных фрагментов текста или кода из редактора в документ `C:\cpp\studyfile.docx`.

Плагин автоматически добавляет к каждому экспортируемому фрагменту имя файла и номер начальной строки выделения, оформляет текст шрифтом `Consolas` с левым отступом и разделительными линиями сверху и снизу, а в конце добавляет пустой абзац-разделитель.

## 2. Архитектура и компоненты

Плагин разработан с использованием **IntelliJ Platform SDK** и библиотеки **Apache POI** для работы с файлами формата `.docx`:

* **`src/main/resources/META-INF/plugin.xml`** — дескриптор плагина: задаёт метаданные плагина, зависимость от `com.intellij.modules.platform` и регистрирует действие `StudyNotesExporter.ExportSelection` в контекстном меню редактора (`EditorPopupMenu`) с горячей клавишей `Ctrl+Alt+Shift+O`.
* **`ExportSelectionAction`** (`com.example.studynotesexporter.ExportSelectionAction`) — класс действия (`AnAction`), который проверяет наличие редактора и непустого выделения, получает `Document` и `VirtualFile`, вычисляет номер начальной строки выделения, вызывает `DocxExporter` и выводит уведомление о результате.
* **`DocxExporter`** (`com.example.studynotesexporter.DocxExporter`) — модуль работы с `.docx`: создаёт при необходимости родительскую директорию, открывает существующий `C:\cpp\studyfile.docx` или создаёт новый `XWPFDocument`, записывает строку `File: <имя_файла> | Line: <номер_строки>`, форматирует строки выделенного текста (`Consolas`, отступ слева, границы сверху и снизу) и добавляет пустой абзац в конце.

### Схема работы

```text
[Выделение в редакторе IDEA]
       │
       ▼
[ExportSelectionAction] ──► получает имя файла и номер строки
       │
       ▼
[DocxExporter (Apache POI)] ──► добавляет метаданные, блок Consolas и пустой абзац
       │
       ▼
[C:\cpp\studyfile.docx] ──► путь по умолчанию (можно поменять под себя в коде, см. пункт 4)
```




## 3. Сборка и установка
1. Соберите дистрибутив плагина в корневой папке проекта:
   ```powershell
   .\gradlew.bat buildPlugin
   ```
2. Возьмите готовый `.zip`-архив из каталога `build\distributions\`.

3. В **IntelliJ IDEA** откройте **Settings -> Plugins -> настройки -> Install Plugin from Disk...**, выберите собранный архив и перезапустите IDE.

4. Перед экспортом закройте файл `C:\cpp\studyfile.docx` (если он открыт), выделите нужный фрагмент в редакторе и вызовите действие через **`Ctrl+Alt+Shift+O`** или контекстное меню редактора.

## 4. Ограничения и настройка пути

* **Настройка пути:** по умолчанию путь сохранения задан как константа `C:\cpp\studyfile.docx` в классе `ExportSelectionAction`. При желании вы можете указать путь к своему файлу в `OUTPUT_PATH` и пересобрать плагин (`.\gradlew.bat buildPlugin`).

* **Область работы:** экспорт работает только для выделенного текста внутри редактора **IntelliJ IDEA**.
