# StudyNotesExporter

Плагин для **IntelliJ IDEA**, позволяющий сохранять выделенные фрагменты кода или текста из редактора в документ `C:\cpp\studyfile.docx` через библиотеку **Apache POI**.  

## Авторство
* **Автор:** Берестюкова Софья Евгеньевна
* **Группа:** М3116

## Возможности
* Экспорт выделенного фрагмента текста из редактора **IntelliJ IDEA** в `C:\cpp\studyfile.docx` (если файл уже существует, новый блок дописывается в конец).
* Автоматическое добавление метаданных перед блоком: `File: <имя_файла> | Line: <номер_строки>`.
* Оформление выделенного текста шрифтом `Consolas` с левым отступом и разделительными линиями сверху и снизу блока.
* Добавление пустого абзаца-разделителя после каждого экспортированного фрагмента.
* Вызов по горячей клавише **`Ctrl+Alt+Shift+O`** или через контекстное меню редактора.
* Возможность при необходимости изменить путь сохранения в константе `OUTPUT_PATH` и пересобрать плагин.
